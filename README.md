# Sistema de Control de Eventos Universitarios

Herramienta diseñada para administrar eventos académicos, sus espacios y asistentes de manera centralizada:

* **Alumnos:** Registro de datos y postulación a eventos.
* **Espacios y Eventos:** Programación de fechas, lugares y cupos máximos.
* **Cronograma de Actividades:** Coordinación de charlas, workshops y seminarios.

---

### Modulos de Última Versión

* Uso de Genéricos y *Wildcards* para un modelado flexible.
* Generación de tickets de ingreso.
* Tareas en paralelo mediante concurrencia.
* Persistencia de datos para la retención del estado del sistema.
